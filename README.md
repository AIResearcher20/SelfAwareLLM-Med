
# SelfAwareLLM-Med  
  
Evaluating semantic self-consistency as a potential reliability signal for medical large language models.  
  
This is a research prototype. It is not a validated clinical tool.  
  
## Status  
  
Results below were generated by this repository on 2026-10-15. Two independent runs of the same 250 questions were performed. Reproducibility at the run level is shown below. Results have not been independently reproduced by a third party.  
  
## Question  
  
Can semantic agreement among multiple responses generated by a medical QA model predict the quality of a separately generated answer?  
  
Consistency is measured as the mean pairwise cosine similarity between embeddings of several responses to the same question. Quality is measured two ways: multiple-choice accuracy against the gold answer, and ROUGE-L against the reference answer text.  
  
## Headline result  
  
Across 250 USMLE-style questions with llama3.2:3b, consistency is positively correlated with multiple-choice accuracy and negatively correlated with ROUGE-L. Two different quality metrics point in opposite directions.  
  
Run 2 (the most recent run) is the primary result:  
  
| method   | n   | rho(accuracy) | p (Bonferroni) | rho(ROUGE-L) | mean accuracy |  
|----------|-----|---------------|----------------|--------------|---------------|  
| auas     | 250 | 0.362         | 2.2e-08        | -0.124       | 0.452         |  
| adaptive | 250 | 0.329         | 6.4e-07        | -0.081       | 0.488         |  
| fixed    | 250 | 0.206         | 6.4e-03        | -0.131       | 0.496         |  
  
All three methods remain significant for accuracy after Bonferroni correction across the six tests (three methods times two metrics).  
  
## Reproducibility across runs  
  
Two runs with identical configuration and seed 13:  
  
| method   | rho(acc) run 1 | rho(acc) run 2 | rho(ROUGE-L) run 1 | rho(ROUGE-L) run 2 |  
|----------|----------------|----------------|--------------------|--------------------|  
| auas     | 0.293          | 0.362          | -0.069             | -0.124             |  
| adaptive | 0.133          | 0.329          | -0.208             | -0.081             |  
| fixed    | 0.228          | 0.206          | -0.185             | -0.131             |  
  
Three things reproduce:  
  
- The sign of the correlation with accuracy is positive in every method and every run.  
- The sign of the correlation with ROUGE-L is negative in every method and every run.  
- auas is the most stable method across runs. adaptive varies more.  
  
The absolute values of rho move between runs because the model is not deterministic even at a fixed seed. The reported intervals are wide: at n=250, the 95% confidence interval for auas accuracy rho is roughly [0.25, 0.47]. Anyone reading these numbers should treat them as a range, not a point estimate.  
  
## Second finding: early stopping predicts correctness  
  
Within the adaptive methods, questions that reached the consistency threshold in 4 samples had much higher accuracy than questions that ran to the cap of 5 samples.  
  
Run 2:  
  
| method   | accuracy at n=4 samples | accuracy at n=5 samples |  
|----------|-------------------------|-------------------------|  
| adaptive | 0.706 (68 questions)    | 0.407 (182 questions)   |  
| auas     | 0.765 (68 questions)    | 0.335 (182 questions)   |  
  
Run 1 showed the same pattern (adaptive: 0.708 vs 0.438; auas: 0.759 vs 0.349). The stopping mechanism itself carries information that the consistency score alone does not.  
  
This is arguably the strongest practical result in this project. A user who only wants a reliability signal can skip the consistency computation and just check whether the sampler stopped early.  
  
## Third finding: consistency groups separate  
  
Run 2, split at the median consistency per method:  
  
| method   | accuracy (low cons.) | accuracy (high cons.) | gap    |  
|----------|----------------------|-----------------------|--------|  
| auas     | 0.264                | 0.640                 | +0.376 |  
| adaptive | 0.344                | 0.632                 | +0.288 |  
| fixed    | 0.400                | 0.592                 | +0.192 |  
  
## Methods  
  
Three samplers are implemented:  
  
- **fixed**: exactly N consistency samples, then one evaluation response.  
- **adaptive**: draws consistency samples one at a time, stops when mean pairwise similarity reaches a threshold or a maximum is hit, then one evaluation response.  
- **auas**: same stopping behavior expressed as an uncertainty threshold (1 - consistency). Included for comparison, not as a novel algorithm.  
  
The evaluation response is an extra model call per question per method. It is not counted in the consistency sample count. Total call counts are recorded per row.  
  
Configuration:  
  
- generation model: llama3.2:3b via Ollama  
- embedding model: nomic-embed-text via Ollama  
- consistency temperature: 1.0  
- evaluation temperature: 0.7  
- adaptive: threshold 0.85, min_samples 4, max_samples 5  
- auas: uncertainty threshold 0.15, min_samples 4, max_samples 5  
- fixed: 5 consistency samples  
- seed: 13  
  
## What is recorded per row  
  
qid, method, consistency, rouge_l, accuracy, n_consistency_samples, stop_reason, valid_responses, failed_responses, generation_calls, embedding_calls, latency_s, error, evaluation_starts_with_letter.  
  
Raw model responses are stored in `responses_{method}.csv` for manual review.  
  
Errors are never converted into empty strings. A failed generation or embedding is counted and marked.  
  
## Run summary  
  
Run 2: 250 questions x 3 methods = 750 model paths, 4364 generation calls, 735 embedding calls, 0 errors, 55 minutes wall clock on a free GitHub-hosted CPU runner.  
  
## Reproducing  
  
Install:  
  
    pip install -r requirements.txt  
    pip install -e .  
  
Build the sample dataset once (needs network and the datasets package):  
  
    pip install datasets  
    python scripts/build_sample.py  
  
Start Ollama and pull the models:  
  
    ollama pull llama3.2:3b  
    ollama pull nomic-embed-text  
  
Run:  
  
    python -m selfaware_med.cli --config configs/experiment.yaml --out-dir results  
  
## Running in CI  
  
`.github/workflows/ci.yml` runs lint and unit tests on every push. It does not download models and does not need network beyond pip.  
  
`.github/workflows/experiment.yml` is triggered manually from the Actions tab. It installs Ollama, caches the models, runs the experiment on a chosen number of questions, and uploads results as artifacts. Free GitHub-hosted runners are CPU-only and time-limited. Start with a small number of questions.  
  
`.github/workflows/save-results.yml` copies an existing run's artifact into `results/` in the repository so the numbers are visible in the file tree.  
  
## Limitations  
  
- Consistency measures semantic resemblance, not truth.  
- ROUGE-L measures surface overlap, not medical correctness.  
- The evaluation target is the reference-based score of one independently generated answer, not the consistency sample set itself.  
- consistency=1.0 does not guarantee a correct answer. Several questions had full agreement on the wrong choice. Examples are visible in `responses_*.csv`.  
- Reported correlations are weak. For auas at n=250 in run 2, r-squared is roughly 0.13. Most of the variance in accuracy is not explained by consistency.  
- Reproducibility is demonstrated at a fixed seed on the same dataset. Whether the same pattern holds on a different 250-question sample is untested.  
- The reported p-values were corrected with Bonferroni across six tests. Uncorrected values were much smaller but would be misleading given the number of comparisons.  
- llama3.2:3b answers 45-50% of these questions correctly. mean ROUGE-L is around 0.09.  
- Ollama does not guarantee identical outputs across versions or hardware even with a fixed seed.  
- The MedQA subset used here is English and multiple-choice. It is not a substitute for clinical evaluation.  
  
## Next steps  
  
- Repeat the run with a second generation model to test whether the ROUGE-L / accuracy divergence and the early-stopping signal reproduce across models.  
- Repeat with a different seed on a different 250-question subset to test sampling stability.  
- Human review of a subset of the raw responses to look for systematic failure modes the metrics do not catch.
